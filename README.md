## 📌 Project Overview
This project focuses on analyzing supermarket sales data using Microsoft Excel. An interactive dashboard was developed to understand sales performance, customer spending, order trends, and delivery time.

## 🎯 Project Objectives
- Analyze supermarket sales and order data.
- Understand customer spending patterns.
- Track order and delivery performance.
- Present key insights through an interactive Excel dashboard.
- Support data-driven business decisions.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Data Visualization
- Excel Dashboard

## 📊 Key Analysis Areas
- Customer Spending Analysis
- Order Analysis
- Order Delivery Time Analysis
- Sales Performance Reporting

## 📁 Project Structure
- `Excel-Dashboard/` – Excel dashboard workbook
- `Dataset/` – Customer, order, and product datasets
- `Images/` – Dashboard screenshots

## 💡 Project Outcome
Created an Excel dashboard to present supermarket sales and order-related insights in a clear and organized format.
